# 文献矩阵（Literature Matrix）

> 工具说明：把「读过」转化为「能写」的核心工具。**行 = 一篇文献，列 = 固定字段，每篇必须填满。**
> 来源：`../docs/THESIS_WRITING_GUIDE.md` §6。
> **写完 20 行，「相关工作」章节与创新点陈述基本自动成型。**
>
> ⚠️ **当前状态：骨架已建，书目信息与结论列均为待填**。下表仅预填了「文献」与「与我的关系」两列
> （后者是整张表的价值所在）。**其余列必须在精读原文后逐篇填写**——不得凭印象填写，
> 也不得引用综述转述（`../docs/THESIS_WRITING_GUIDE.md` §4）。

## 「与我的关系」列只有三种取值

| 取值 | 含义 |

| **支持我** | 为我的设计提供依据 |
| **我改进它** | 我解决了它的问题 |
| **我反对它** | 我是它的反例 / 基线 |

## 填充流程（`../docs/THESIS_WRITING_GUIDE.md` §6）

```
检索 → 筛选（读摘要）→ 精读（读方法 + 实验）→ 填矩阵 → 归类 → 写作
```

- **工具**：Zotero（内置 GB/T 7714 样式）+ BibTeX
- **原则**：**填矩阵与精读同步进行**，不要读完再回头整理
- **顺序**：先填 A 组（6 篇竞争工作，决定论文能否成立）→ 再填 B 组（基线）→ C 组（数据集原文）→ D 组

## 参考文献格式

| 场景 | 标准 |
|---|---|
| 国内学位论文 | GB/T 7714 |
| 国际会议 / 期刊 | IEEE / ACM（按目标会议模板） |
| 正文引用制式 | 顺序编码 `[1]` 或 著者-出版年 `(Zhang et al., 2023)`，**全文必须统一** |

**四种必须避免的错误**：引而不注（学术不端）、转引不注、注而不引、张冠李戴。
（`../docs/THESIS_WRITING_GUIDE.md` §5）
