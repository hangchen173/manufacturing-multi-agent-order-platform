## 阅读顺序建议

**若目标是 2027 级考研复试（当前场景）**
1. `KYAN_RETEST_STRATEGY.md` — 先看双窗口规划与「投出去」的认定口径，**第一步是查目标院校细则**
2. `CCF_C_SUBMISSION_GAP.md` — 确认对口期刊与必须避开的预警期刊
3. `PAPER_PLAN_SCI_Q1.md` — 论文按此推进（执行主体）
4. `COURSE_DESIGN_REVIEW.md` — 项目实测数据即面试叙事的证据来源

**若目标是本科毕设答辩**
1. `COURSE_DESIGN_REVIEW.md` — 先看项目当前水平与不足
2. `THESIS_WRITING_GUIDE.md` — 再补写作规范

**若目标是读研 / 发表论文**
1. `MASTER_DEGREE_REQUIREMENT_CHECKLIST.md` — 先确认毕业门槛（可能不需要发论文）
2. `GRADUATION_TIMELINE.md` — 若时间紧张，看这份的可行性分析与分层下注策略
3. `PUBLICATION_TIERS.md` — 建立期刊层级的坐标感
4. `CCF_C_SUBMISSION_GAP.md` — 盘点与投稿要求的差距
5. `PAPER_PLAN_SCI_Q1.md` — 按详细规划执行（先做 §2.3 的 2 周判决实验）

## 需要注意的两点

### 一、两份论文规划存在重叠

`PAPER_PLAN.md` 与 `PAPER_PLAN_SCI_Q1.md` 覆盖同一主题，由不同来源生成，**建议合并保留一份**。

- `PAPER_PLAN_SCI_Q1.md`（详版，19 KB）更完整：给机制起了名字（VEAP）、列 4 条贡献、
  设计了 2 周可完成的新颖性判决实验、补了 IPM 这一更对口的期刊、给出 Related Work 差异表。
- `PAPER_PLAN.md`（简版，14 KB）结构更清晰：七章结构与素材来源映射、术语翻译表。

**建议**：以详版为主体，把简版的「术语翻译表」并入其中。

### 二、所有结论都有时效性

- **期刊分区与影响因子每年更新**，投稿前须重新核对。
- **CCF 目录有 2019 版与 2022 版**，部分学校使用自定版本。
- **学校认定规则可能逐年调整**，务必以**本人入学年级**的最新文件为准，不要参考往届经验。
