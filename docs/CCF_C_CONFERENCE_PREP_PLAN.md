## 5. 时间不足时的取舍顺序

> 时间只剩 10 周（docs 自估需 4–6 个月全职），取舍不可避免。**按以下顺序砍，先砍后面的。**

1. 数据集数量：4 个 → 3 个（保留自建 + 1 公开 + 1 中文）
2. 基线数量：8 个 → 5 个（保留 self-consistency、self-refine、MAD、LLM-as-Judge、MoA）
3. 消融项：6 项 → 3 项（**必须保留 A1 证据形态、A2 上下文隔离**）
4. 目标档位：降级为「保底档」会议/期刊

**绝对不能砍的三项：**
- 新颖性判决（决定方向是否成立）
- **证据形态的对照实验（A1）——这是论文的核心贡献，砍了就没有论文**
- 统计重复与显著性（审稿人必查）
