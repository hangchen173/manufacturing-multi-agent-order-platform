# 毕业时间线与投稿可行性分析

> 起点：2026-10-01
> 假设毕业时间：2027-06（如不同请按比例调整）
> 可用时间：约 8–9 个月
> 目标档位：中等偏上（CCF-C 且中科院一区 TOP，如 IPM / ESWA / EAAI / KBS）

---

## 0. 结论

| 毕业要求 | 能否在一年内达到中等偏上 | 说明 |
|---|---|---|
| **不要求发表** | 不是问题 | 论文是加分项而非必需品。多校已按「破五唯」取消硬性要求 |
| **要求「录用」** | **极紧，不建议押注** | 需零拒稿 + 零大修。一区期刊录用率通常 10–20% |
| **要求「见刊」** | **基本不可能** | 录用后仍需 2–6 个月出版流程 |

**核心风险**：一区期刊一审周期（3–6 个月）本身就跨过毕业线，且一审只是开始，之后还有大修或拒稿改投。

---

## 1. 时间线（假设全职投入）

| 阶段 | 时间 | 说明 |
|---|---|---|
| 新颖性判决 + 文献矩阵 | 2026-10（2 周） | **成败关键，不可跳过** |
| 修跨域能力 + 问题形式化 | 2026-10 → 11 | CORD 0/100 需解决或转为边界声明 |
| 实现 8 个基线 | 2026-11 → 12 | 从零开始 |
| 主实验 + 消融 + 统计 | 2026-12 → 2027-01 | 含 3 次重复与显著性检验 |
| 写作 + 英文润色 | 2027-01 → 02 | |
| **投一区期刊** | **2027-02** | |
| **一审返回** | **2027-08** | **已过毕业线 2 个月** |

### 时间线的三个缺口

1. **一审返回晚于毕业**——即使一切顺利，也赶不上。
2. **未计入大修**——若一审给 major revision，再加 1–2 个月。
3. **未计入拒稿**——若被拒改投，重新计时 4–6 个月。

**若要求「见刊」，再叠加出版流程 2–6 个月。**

---

## 2. 三个硬约束

| 约束 | 说明 |
|---|---|
| **审稿周期不可控** | 与努力程度无关。一区期刊一审 3–6 个月是常态 |
| **实验工作量被低估** | 8 基线 × 4 数据集 × 3 重复；实现基线本身需 3–4 周。上述估算前提是**全职投入**，若同时写学位论文、上课、找工作，实际可用时间可能减半 |
| **学位论文优先级更高** | 不能因投稿耽误学位论文写作与答辩 |

---

## 3. 建议策略：分层下注

**不要把毕业押在一区期刊上。** 用分层策略把「保毕业」与「冲高水平」解耦。

### 第一步：保底（2026-11 前投出）

把现有工作整理成一个**完整版本**，投审稿快的出口：

| 出口 | 审稿周期 | 说明 |
|---|---|---|
| **快速会议**（如 ICDAR 等 CCF-C 会议） | 2–3 个月 | 领域对口、周期短 |
| 审稿快的期刊 | 3–4 个月 | 需查期刊官网的平均审稿周期 |

**目标**：11–12 月投出 → 次年 2–3 月录用 → **先满足毕业要求**。

### 第二步：冲高（2027-02 后投出）

把**扩展版**投一区期刊（IPM / EAAI / ESWA）。

- 期刊版需比会议版有**实质增量**（通常要求 30%+ 新内容）
- 必须**明确引用**会议版
- **投稿前确认目标期刊是否接受会议扩展版**（多数接受，少数明确不接受）
- **不必赶在毕业前**——录用后是读研/求职的成果，与毕业解耦

### 心态调整

把「一区期刊」从**毕业要求**降级为**长期目标**。这样即使被拒，毕业也不受影响。

去学院研究生教务索取**本人入学年级**的《研究生申请学位科研成果认定办法》，确认：

## 5. 时间紧张时的取舍原则

若时间不足，按以下顺序**砍需求**（先砍后面的）：

1. 数据集数量：4 个 → 3 个（保留自建 + 1 个公开 + 1 个中文）
2. 基线数量：8 个 → 5 个（保留 self-consistency、self-refine、MAD、LLM-as-Judge、MoA）
3. 消融项：6 项 → 3 项（**必须保留证据形态 A1 与上下文隔离 A2**）
4. 目标档位：一区 → 二至三区（保底档同样满足多数毕业要求）

**绝对不能砍的**：
- 新颖性判决（决定方向是否成立）
- 证据形态的对照实验（这是论文的核心贡献）
- 统计重复与显著性（审稿人会查）
